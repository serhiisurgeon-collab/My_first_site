- UA/EN title та H1 точно відповідають завданню. Бренд і старі URL збережені.
- Чотири локалізовані description, Open Graph, Twitter, описи соціальної обкладинки, власні canonical, взаємні чотири hreflang включно із самою сторінкою. Примусових мовних редиректів немає.
- Основний зміст у початковому HTML: шість наявних карток можливостей, чотири нові мовні блоки, сім практичних FAQ-відповідей, налаштування й умови доступу. Немає FAQ JSON-LD чи обіцянок розширених результатів Google.
- Пояснено формулу 4 × 3, незалежну мову меню, відмінність навчання та перекладу. A1/A2/B1 не названо повними курсами чи гарантією рівня.
- Шрифти, світла палітра, спільні CSS/JS і загальна композиція збережені. Заголовки адаптовано до довжини; DE/ES меню на середніх екранах перемикається в мобільний вигляд.
- Повністю локалізовано основний зміст, FAQ, кнопки, меню, підвал і службові підписи DE/ES. Посилання на решту сайту ведуть до чинних EN-сторінок і явно позначені «auf Englisch» / «en inglés».
- Додано перемикач UA/EN/DE/ES. На нових DE/ES сторінках не підключено україномовний fallback пошуку; навігація та обробка посилань використовують чинні спільні модулі без дублювання.
- Демонстраційна іспанська картка: незмінна база із 30 записів і UTC-цикл. На DE/ES локалізовано підписи та дату; переклад прикладу лишається англійським і саме так позначений, без вигаданих навчальних перекладів.
- Нові DE/ES адреси внесено в `tools/seo/build.mjs`, згенерований реєстр і sitemap. У sitemap тепер 30 адрес. `robots.txt` уже дозволяє обхід і містить адресу sitemap; змін не потребував.
- Картки на головній, у Projects і записи пошуку вже описують чотири мови після попереднього оновлення; повторне дублювання чи зміна їхніх правильних посилань не знадобилися.

## Достовірність продукту

Власник надав витяг із опублікованого коду `telegram_bot 36297ad` / `spanish_quiz 0916afb` і підтвердження роботи розгорнутої версії. Незалежної перевірки Render, коду цих репозиторіїв або приватних даних користувачів тут не виконувалося.

Додано на всі мовні версії реальні матеріали з підтверджень власника (перші три — A1):
- українська: `квиток`, «У мене є квиток до Львова.»;
- англійська: `a suitcase`, «My suitcase is under the bed.»;
- німецька: `der Bahnhof`, «Der Bahnhof ist neben dem Hotel.»;
- іспанська: `tener ganas de`, «Tengo ganas de dar un paseo.» — чинність окремо підтверджена власником. Точний рівень цього вислову не заявляється, оскільки його не наведено у підтвердженні.

Переклади взято з того ж повідомлення, з правильними `lang`. Жодної вправи чи зображення для бота не вигадано. Приклади показані як статичні матеріали, без імітації реального квізу.

Уточнено Free: базова добірка слів/висловів, базові вірші, зображення з підписами, мовні налаштування, нагадування й базовий звіт. Premium: вибір рівня для відповідних матеріалів, рівневі вірші, WebApp-квізи й результати. Квіз має **до 20** питань. У звіті — сьогодні та шість попередніх календарних днів UTC; враховуються прийняті відповіді незавершених квізів. Видача матеріалу не названа підтвердженим прочитанням або засвоєнням. Добровільна підтримка не названа придбанням Premium.

Неопубліковане розширення української бази не описується як чинна можливість. Публічних технічних подробиць про хостинг, API, базу, коміти чи адміністрування немає.

Іспанський вислів із наявної JSON-картки власник додатково підтвердив як чинний запис бота. Усі чотири мовні блоки мають приклади; вигаданих матеріалів немає.

## Аналітика

У поточних HTML, шаблонах і прикладному JS не знайдено завантаження GA4/GTM, Measurement ID, існуючого обробника Telegram-кліків або керування згодою на аналітику. Згадки consent у Firebase стосуються коментарів, а не згоди на GA4. Це висновок про код, не про налаштування Google-акаунта власника.

`js/telegram-analytics.js` готує одну подію `telegram_bot_click` з параметрами `page_language` та `button_location`. На кнопках задані стабільні позиції: hero, getting-started, free, premium, language-uk/en/de/es. Не передаються імена, email, UID, текст відповіді чи URL-параметри.

Адаптер **не активовано і не імпортовано лендингами**. Він не встановлює cookies, не підключає GA4 і не надсилає нічого самостійно. Для активації потрібні справжні адаптери `hasAnalyticsConsent()` і `sendEvent()`. Згода читається при кожному кліку; відкликання діє одразу. Повторна ініціалізація не дублює обробник; помилка аналітики не блокує навігацію.

Власник підтвердив: механізму згоди немає. Тому надсилання не активується. Для окремого майбутнього ввімкнення потрібні публічний GA4 Measurement ID і погоджена реалізація згоди. Не заявляється, що кліки вже збираються в GA4. Після інтеграції також перевірити, чи не дублює збір Enhanced Measurement/outbound clicks, та перевірити подію в DebugView за наданої згоди.

- `npm run seo:build` / `npm run seo:check`: 44 відтворювані результати, 10 сторінок статей; реєстр і sitemap актуальні.
- `npm run seo:test`: 19/19 успішні.
- `npm run seo:jekyll`: офіційна локальна збірка успішна.
- `npm run seo:public-check`: 205 файлів; службові/приватні файли й ключі виключено.
- `node tests/spanish/seo-landings.mjs`: 20 комбінацій (4 мови × 360/390/768/1024/1440 px), правильні метадані, чотири hreflang, sitemap, меню, взаємне перемикання, усі внутрішні посилання/ресурси, відсутність горизонтального переповнення, локальних 404 і page errors. Чотири додаткові сценарії без JS; ізольована перевірка згоди, її відкликання та недублювання події.
- Знімки desktop/mobile усіх чотирьох мов у `/workspace/artifacts/spanish-seo-four-locales/`. Візуально переглянуто, зокрема довгий німецький H1.
- Браузер: Chromium; реальні iPhone/Safari окремо не перевірялися. Зовнішні шрифти/іконки в тестах завантажувалися TLS-перевіреним curl; інші сторонні звернення блокувалися.
- Чинні публічні UA/EN URL повертають HTTP 200; у їхніх HTTP-заголовках не знайдено X-Robots-Tag. Це перевірка вихідного живого сайту, а не публікації нової версії. DE/ES HTTP 200 перевірено локально; публічний статус потребує повторення після публікації.
- Регресійні `node tests/spanish/four-languages.mjs` та `node tests/spanish/discovery.mjs`: 14 браузерних сценаріїв, 60 UTC-індексів, реальна зміна дня на межі 30-денного циклу, повторна поява карток, резервний JSON, four-card discovery і пошук — успішні.
- Фактична індексація, позиції та результат обробки Google Search Console не перевірялися й не заявляються.

## Порядок публікації й дії власника

1. Звірення іспанського прикладу завершене. Аналітика залишається вимкненою за відсутності згоди; SEO не залежить від її збору.
2. Опублікувати перевірену гілку через чинний main → Jekyll → GitHub Pages. DNS/Firebase/налаштування Search Console не змінювати.
3. Звірити всі чотири живі URL: HTTP 200, відсутність X-Robots-Tag/noindex, власні canonical, повний HTML, ресурси, sitemap і перемикання мов.
4. У Google Search Console перевірити **кожен із чотирьох URL** через URL Inspection / Live Test. Після успішної перевірки запросити індексацію оновлених UA/EN та нових DE/ES. Звірити успішну обробку оновленого sitemap. Це не гарантує індексації або позицій.

Відкат — revert лише SEO-коміту сайту, без Firestore. Якщо нові URL вже опубліковані й поширені, перед відкатом зберегти доступні сторінки-переходи на відповідний матеріал, а не залишати зовнішні посилання без цілі. GA4 не активовано, тому відновлювати або змінювати дані аналітики не потрібно.
